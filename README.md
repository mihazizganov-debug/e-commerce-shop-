## 📋 Домашнее задание 16.1

### ✅ Реализовано:

#### 1. **Приватные атрибуты и методы доступа**:
   - Класс `Category`: атрибут `products` сделан приватным (`__products`)
   - Класс `Product`: атрибут `price` сделан приватным (`_price`)
   - Реализован метод `Category.add_product()` для добавления товаров
   - Метод увеличивает класс-атрибут счетчика продуктов

#### 2. **Геттеры и сеттеры**:
   - Геттер `@property` для `Category.products` с форматированным выводом
   - Каждый продукт выводится в формате: `"Название продукта, X руб. Остаток: X шт.\n"`
   - Геттер и сеттер для `Product.price` с использованием `@property` и `@price.setter`
   - Сеттер проверяет, что цена положительная, иначе выводит сообщение

#### 3. **Класс-метод**:
   - Добавлен класс-метод `Product.new_product()` с декоратором `@classmethod`
   - Принимает словарь с данными товара, возвращает экземпляр `Product`

#### 4. **Строковое представление объектов**:
   - Класс Product: реализован метод __str__
   - Возвращает строку: "Название продукта, X руб. Остаток: X шт."
   - Класс Category: реализован метод __str__
   - Возвращает строку: "Название категории, количество продуктов: X шт."
   - Метод __str__ рассчитывает общее количество товаров на складе (quantity) для каждого продукта в приватном атрибуте __products

#### 5. **Магический метод сложения**:
   - Класс Product: реализован магический метод сложения __add__
   - Метод принимает два аргумента: self и второй объект
   - Метод возвращает сумму произведений цены на количество у двух объектов

#### 6. **Классы-наследники**:
   - Создан класс `Smartphone` (наследник `Product`) с атрибутами:
     - `efficiency` - производительность
     - `model` - модель

## 🚀 Как запустить проект:

```bash
# 1. Клонирование репозитория
git clone https://github.com/mihazizganov-debug/e-commerce-shop-.git
cd e-commerce-shop-

# 2. Установка Poetry (если еще не установлен)
# Для Windows:
pip install poetry

# 3. Установка зависимостей
poetry install

# 4. Активация виртуального окружения
poetry shell

# 5. Запуск основного кода
python main.py

# 6. Запуск тестов
pytest tests/

# 7. Проверка покрытия
pytest tests/ --cov=src

# 8. Проверка стиля кода
flake8 src/ tests/ main.py
black --check src/ tests/ main.py
isort --check-only src/ tests/ main.py
mypy src/ tests/ main.py
```
